# PagPasteleriaReact
Pagina creada para y por una tienda que vende pasteles cremosos, su especialidad 

Creacion de proyecto:
1. Debe estar activa la ultima version de vite (nvm install latest 'then' nvm use latest )
2. Debe crear archivos de bootstrap, vitest y etc (npm install)
3. Para correr los tests usar npm run test:watch (para informacion mas detallada)
4. Para levantar la pagina usar npm run dev
